Common Mistakes in Graph Problems

1. Not marking nodes as visited, leading to infinite loops or revisiting.
2. Using the wrong traversal (DFS vs BFS) for the problem type.
3. Forgetting to reset visited array between test cases.
4. Not handling disconnected components (missing some nodes).
5. Incorrect edge direction in directed graphs.
6. Not checking for cycles when required (e.g., topological sort).
7. Overflow in recursion (stack overflow in deep DFS).
8. Not handling self-loops or multiple edges properly.
9. Using adjacency matrix when adjacency list is more efficient (or vice versa).
10. Not considering edge cases (empty graph, single node, no edges).
