Common Mistakes in DSA Problems (General)

1. Off-by-one errors in loops and array indices.
2. Index out of bounds (e.g., accessing arr[n] instead of arr[n-1]).
3. Not resetting variables or data structures between test cases.
4. Mutating collections while iterating without proper care.
5. Using the wrong data structure for the problem (e.g., map vs unordered_map).
6. Not considering edge cases (empty input, single element, duplicates).
7. Forgetting to handle negative numbers or large values (overflow).
8. Infinite loops due to incorrect pointer or loop updates.
9. Not checking constraints or input limits.
10. Poorly defined conditions in sliding window or two-pointer problems.
